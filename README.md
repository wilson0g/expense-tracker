# Expense Tracker

Expense Tracker is a simple web application designed to help users manage their personal finances by setting budgets, recording expenses, and monitoring their spending.

This project was developed as part of my Web Technologies coursework.

## Features

- **Budget Management:** Set a budget and track how much money is available.
- **Expense Recording:** Add expenses and organize them into categories.
- **Expense List:** View and delete recorded expenses.
- **Category Filtering:** Filter expenses based on their categories.
- **Spending Summary:** View total expenses, budget information, and spending statistics.
- **Local Storage:** Save budget and expense information in the browser so that data remains available after refreshing the page.
- **Page Navigation:** Move between the Home, Expenses, and Summary pages.

## Technologies Used

- **HTML5:** Structures the web pages.
- **CSS3:** Styles the website and its layout.
- **JavaScript:** Handles calculations, user interactions, and expense management.
- **LocalStorage:** Stores user data in the browser.

## Project Files

- `index.html` – Home page and budget management.
- `expenses.html` – Expense recording, viewing, filtering, and deletion.
- `summary.html` – Budget and expense summaries.
- `thecsspart.css` – Shared styling for the website.
- `script.js` – JavaScript functionality and data storage.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Set your budget and start recording expenses.
5. Navigate between the pages to manage expenses and view your spending summary.

No additional software, database, or server is required.
